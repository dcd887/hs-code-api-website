Privacy Policy

Last updated: September 12, 2026

This Privacy Policy describes how HS Code Classifier API ("we", "us", "our") collects, uses, and protects your personal information when you use our API service and website.

1. Information We Collect

1.1 Account Information

  • Email address: Required for account creation, API key delivery, and communication
  • API keys: Generated for authentication and usage tracking
  • Plan type: Your subscription tier (Basic, Pro, Ultra)

1.2 Usage Data

  • API requests: Product names and classification queries you submit
  • Usage logs: Timestamps, endpoints accessed, and request volumes
  • IP addresses: Collected for security and rate limiting purposes

1.3 Payment Information

We do not store credit card or payment information directly. All payments are processed through Creem, a secure payment processor. We receive only payment confirmation and order details.

2. How We Use Your Information

  • To provide and maintain our API service
  • To process transactions and send API keys
  • To track API usage and enforce rate limits
  • To improve our classification accuracy and service quality
  • To send service-related notifications (updates, security alerts)
  • To respond to customer support inquiries

3. Data Storage and Security

  • API keys and account data are stored in secure databases on our servers
  • We use industry-standard security measures to protect your data
  • API request logs are retained for up to 90 days for debugging and security purposes
  • We do not sell, rent, or share your personal information with third parties for marketing purposes

4. Data Sharing

We may share your information with:

  • Payment processors: Creem, for transaction processing
  • AI service providers: Our classification engine uses third-party AI APIs. Product queries are sent to these providers for processing but are not stored by them
  • Legal requirements: When required by law or to protect our rights
